# :books: Conceptos

Esta carpeta contiene los conceptos fundamentales utilizados en el laboratorio **CyberSOC**.

Su objetivo es proporcionar el contexto necesario para comprender **qué hace cada componente y cómo se relacionan entre sí** antes de comenzar la implementación práctica.

No es necesario estudiar cada tecnología en profundidad. Cada documento está enfocado únicamente en **lo que necesitamos conocer para este laboratorio**.

## :compass: Orden recomendado

Se recomienda leer los documentos en este orden:

1. [Wazuh](./01-wazuh.md)
2. [Docker](./02-docker.md)
3. [Suricata](./03-suricata.md)
4. [Threat Intelligence](./04-threat-intelligence.md)
5. [YARA](./05-yara.md)
6. [FIM](./06-fim.md)
7. [Threat Hunting](./07-threat-hunting.md)

El orden va desde los componentes principales del entorno hasta la **investigación y correlación de evidencias**.
